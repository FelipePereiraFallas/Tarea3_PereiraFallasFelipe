## Descripción

En este repositorio se encuentra el desarrollo de la tarea 3 del curso de Herramientas de Ciencias de Datos I.

## Contenido

- cod/: funciones y scripts de R
- data/: datos generados
- config/: parámetros para los ejercicios
- excel/: libro de excel con cálculos
- info/figuras: gráficos solicitados
- base/: código base

## Reproducción

1. Clonar el repositorio
2. Clonar la base del docente dentro de base/
3. Ejecutar cod/01_datos.R para generar los datos y parámetros
4. Ejecutar el reporte de Quarto para los resultados 

## Ejercicios

1. Alertas por ventana móvil
2. Ley de Benford por cantón
3. Valor acumulado con interés
